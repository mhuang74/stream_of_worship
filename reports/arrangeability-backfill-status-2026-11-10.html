1. What was broken

Two independent gaps made recordings unusable in the Arrange editor:

  • No arrangement structure — recordings.sections and recordings.beats were empty, so the webapp's buildSnappedSteps returned nothing and the Arrange button stayed disabled. 22 review + 5 published recordings were affected (10 of the review ones also lacked components).
  • No component analysis — no song_components rows, so the songs had no entry / exit / loop-target roles and no theme or vocal-posture classification. 116 review recordings were affected.
Root cause of the structure gap was not a missing beat grid. All 27 recordings already had a cached beat grid in R2 (beat-grid reported already_present for every one). The failure was in the lyric timeline: write-structure returned no_structure because the LRC lyrics and structured_lyrics did not agree line-for-line — a large share of the LRC files were placeholders (此歌曲暂无歌词) or had words the aligner could not match, and several recordings had no usable vocals stem at all.

The second root cause: a broken stem pipeline

  • MVSEP (the cloud separator) was returning queue full: "You already have unprocessed file in queue" on every submit — including at concurrency 1, so the blockage was server-side, not local parallelism.
  • Some recordings had a vocals_dry.flac in R2 that was digital silence — for 在祢殿中 it measured -77.5 dB mean / -48.9 dB peak over the whole 203.8 s track. Whisper and Qwen3 ASR both transcribed that stem and found nothing, which looked like "untranscribable audio" but was really "empty stem".
  • Fix applied: run the service with SOW_MVSEP_ENABLED=false. With MVSEP disabled the client is never constructed, so separation fails over immediately to the Modal sow-stems app (Demucs / mel-band-roformer) with no quota wait. Regenerated stems were then transcribed with Qwen3 ASR and aligned by the LLM. The only cost was Modal L4 GPU queueing, typically 20–25 minutes per call.

7. How to reproduce / roll back

set -a; . /opt/sow/.env; set +a
ADMIN='uv run --project ops/admin-cli --extra admin sow-admin'

# structure (uses cached beat grids; no LLM)
$ADMIN audio beat-grid       --stdin --include-published --format json < ids.txt
$ADMIN audio write-structure --stdin --include-published --format json < ids.txt

# components
$ADMIN audio sync-components --stdin --format json < ids.txt
$ADMIN audio components      --stdin --compute-all-fields   < ids.txt

# re-separate stems on Modal instead of MVSEP, then transcribe
SOW_MVSEP_ENABLED=false docker compose up -d --force-recreate analysis-dev
$ADMIN lyrics generate <song_id> -g qwen3 --force --no-cache
