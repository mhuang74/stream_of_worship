## Provider nondeterminism (critical finding)

The configured production model (`qwen3.6-35b-fast` via neuralwatt) is **not
deterministic at `temperature=0`**. Repeated runs of the identical prompt + few-shot
config produce materially different segmentations and scores:

- `V3_trio` few-shot, default prompt: observed grand totals `[0.641, 0.641, 0.363, 0.485, 0.485, 0.363, 0.363]` → median 0.485, best 0.641.
- `jun_wang_jiu_zai_zhe_li_1c32724c` with `V3_trio`: `0.844` in one batch, `0.010` (zero choruses) in another.

This run-to-run variance makes single-run axis comparisons unreliable and prevents a
stable 0.70 result. The tuning loop's assumption of deterministic outputs (temp 0) does
not hold for this provider.

## A3 — Validator weights grid (no effect on IoU)

The four `ValidatorWeights` knobs (`nonrepeated_multiplier`, `trimmed_multiplier`,
`confirmed_bonus`, `mapping_confidence_multiplier`) only scale `ComponentInstance.confidence`.
The IoU scorer (`_score_components`) scores on `start_time`/`end_time` and `role` only —
**confidence is not used**. Therefore the A3 grid has no effect on the grand-total IoU.
`DEFAULT_VALIDATOR_WEIGHTS` is left unchanged.

## Failure modes (per-song)

- **`yi_sheng_jing_bai_mi_da2173d0` (stuck ~0.079):** the LLM splits the chorus
  `我要一生 一生敬拜祢 / 在祢殿中瞻仰祢榮美 / …` into a single-line hook chorus plus a
  "bridge", and emits a spurious chorus on line 13 (the prechorus's last line, which is
  textually identical to the chorus hook). The spurious chorus makes the true middle
  chorus `role="none"`, which the scorer filters out. A `wo_yao_chang_chang_xi_le`
  few-shot example (hook + continuation chorus) raised it to 0.538 but regressed
  `jun_wang`.
- **`jun_wang_jiu_zai_zhe_li_1c32724c` (0.01–0.844):** the LLM merges the opening verse
  (lines 3–4, `聖潔耶穌 祢寶座在這裡…`) into the first chorus and over-merges chorus
  boundaries; sometimes it emits zero choruses entirely (parse/label failure).
- **`zhu_a__wo_yao_gen_sui_mi_83163301` (1.000, stable):** perfect.

## Conclusion

The LLM segmentation path is a clear improvement over the lyrics-repetition baseline
(0.286 → ~0.49 median / 0.64 best). The 0.70 pass bar is not reliably met because (a) the
provider is non-deterministic at temperature 0, and (b) two of the three fixtures
(`jun_wang`, `yi_sheng`) have hard boundary cases (chorus-splitting and opening-verse
merging). Reaching 0.70 reliably would require either a deterministic provider/model or
additional fixture coverage.
